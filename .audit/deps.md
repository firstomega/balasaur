SUMMARY:
About a fifth of the source tree is code nothing can reach. Walking imports outward from the 35 route and server entry files, 35 files totalling 2,983 lines are never reached, including src/components/ui/sidebar.tsx at 745 lines and 23 of the 41 shadcn components, which have zero importers anywhere. That dead tree is the only reason 21 npm packages are installed: 16 Radix packages plus cmdk, react-hook-form, input-otp, @hookform/resolvers and date-fns, and date-fns alone is 39 MB on disk with zero references in src. The good news is that none of it reaches a visitor. Grepping the 48 built client chunks for Menubar, Sidebar, AlertDialog, cmdk, useFormContext and date-fns returns zero hits, so tree shaking is doing its job and the dead code costs maintenance and install time, not download bytes. What visitors do pay for is the shared entry chunk: 641 KB raw, 191 KB gzipped, imported by all 41 route chunks, and its single largest ingredient is the Supabase client at 793 KB of source, 34% of the chunk and more than React and React DOM combined at 551 KB. Inside that, storage-js contributes 101 KB and there is not one `.storage.` call site in the entire codebase.

STRENGTHS:
- Tree shaking is clean. All 23 dead shadcn components, plus cmdk, react-hook-form and date-fns, appear in 0 of the 48 built client chunks. The bloat is inert from the visitor's point of view.
- Route splitting works. Distinctive strings from src/routes/index.tsx appear 0 times in the shared entry chunk and only in its own route chunk, so the homepage is not being dragged onto every page.
- No duplicate utilities where it would matter most. src/lib/rank.ts (computeRankScore, the 45/40/15 popularity, quality and recency blend) and src/lib/score.ts (computeBalasaurScore, the IMDb/RT/Metacritic/TMDB blend) are genuinely different functions, each with a comment naming the SQL column it must stay in sync with. This is the part of the codebase most likely to grow a near-copy, and it has not.
- Dependency list is boring in the right way. No moment, no lodash, no chart library, no animation library. React 19, Tailwind 4, TanStack current. `bun run build` finished in 7.09 seconds and `bunx tsc --noEmit` exits 0.
- Total client payload is 1,082 KB raw across 48 files, 320 KB gzipped, with CSS at 102 KB raw and 17 KB gzipped. Tailwind is not leaking a full utility sheet.
